## 四条要拍板的

### 1. ADR-0011 还成不成立(最要紧)

「RoboDK 负责仿真,也通过它的驱动控制真机,程序只写一套」——**控真机这一半出了大问题**:

- **速度设不了。** 试了四条通道全部无效:`setSpeedJoints()`、控制柜倍率 `set_rapidrate()`、
  `setParam("Driver","SPEED …")`(返回空串,驱动不支持)、程序里的 `INS_TYPE_CHANGESPEED`
  指令 + `RunProgram()`(程序根本没执行)。下发速度改 8 倍、倍率改 2.6 倍,耗时都在
  0.37–0.55 秒之间,毫无响应。
- **实际速度超了约定上限。** 拟合出加速度约 30 °/s²,1° 峰值约 5.5 °/s、2° 约 7.4 °/s,
  外推 5.5° 约 13 °/s;约定上限是 ≤5 °/s。
- 后果:演示要的「回待命 10 °/s」「直线 50 mm/s」「慢速走」全部落空;
  第 2 段(断连保险)要的 9 秒慢速运动这条路产生不了,所以后面五段都做不下去。

可选(我的排序):

1. **先试官方 `jkrc` 直控这条退路**(ADR-0011 里本来就写了这条退路)。
   `jkrc.joint_move(joint_pos, move_mode, is_block, speed)` 自带 speed 参数,
   `motion_abort` 也在,叫停有着落。代价:RoboDK 只做仿真,真机那一层要自己写,
   JAKA 和 Dobot 不再共用一套下发代码(但上面的状态逻辑、路点、配置仍可共用)。
   **验证只要一次 1° 的小运动**,很便宜。
2. 继续查 RoboDK 为什么 `RunProgram()` 没执行,把「走程序」这条路走通。
   可能能救回 ADR-0011,但耗时不确定,而且叫停、读位置那两个问题还在(见第 2 条)。
3. 升级 RoboDK(要下载安装,先问用户;还要看许可证能不能升)。
4. 放弃用 RoboDK 控真机,改成「RoboDK 只做仿真 + 每台自己的官方 SDK」,
   这其实就是方案 1 推广到两台。

### 2. 叫停怎么做(ADR-0012 和「叫停在 RoboDK API 这一层的做法」)

仿真里定下的是「非阻塞 + `Busy()` 轮询,同一条连接上调 `Stop()`」。真机上:

- **运动中调 `robot.Joints()` 会让 RoboDK 5.9.0 崩进程**(崩 1 次 / 不调则 4 次都没事)。
  所以「执行线程轮询 + 同时读位置画预览」这种写法要避开。
- **运动中拿不到位置曲线。** `get_joint_position` 被运动挤住(丢过 1.5 秒);
  `get_robot_status` 的缓存在运动全程冻结,滞后约 1.0 秒,只给起点和终点两个值。
- `Busy()` 大致可信但分辨率只有几十毫秒。
- **`Stop()` 本身这次根本没测到**(没跑到第 3 段)。

要定:叫停这条路是留在 RoboDK(那就得先解决速度),还是跟着第 1 条一起换到 `jkrc`
(`motion_abort`)。另外**验收里「0.5 秒内停住」在真机上目前测不了**,要么改成
只看「最终停在半路」,要么换控制路径后重测。

### 3. ADR-0005(速度倍率换算)

「JAKA 对所有运动生效……由程序在下发前把倍率换算掉」——**倍率对经 RoboDK 驱动下发的运动
不生效**(13% → 5%,耗时 0.370 → 0.431 s,差一个轮询间隔)。这条要作废或重写。
换到 `jkrc` 以后倍率生不生效,要重新测。

## 已经可以直接吸收的(不用再问)

- **第 1 段通过:** 驱动能连(0.2–0.6 s),读回的关节角和真机完全一致,运动的净转角准确。
- **连上不会自动上电使能。** 驱动里根本没有 `power_on` / `enable_robot`。
  → 决策「程序连上机械臂后自动上电、使能」在 JAKA 上要改成
  **由人在示教器上上电使能,程序只检查不执行**。
- **判断使能要用 `get_robot_status()[1][3]`,不能用 `get_robot_state()` 的第三位**
  (那一位上电后仍是 0,推测是 servo 流模式)。
- **RoboDK 的 Python 必须是 3.7–3.12。** `jkrc.pyd` 在 3.12 里 import 就 SystemError,
  实际可用的是 RoboDK 自带的嵌入式 3.10。**RoboDK 的 Python 设成 3.13 会让 JAKA 驱动加载失败。**
  → 这条要写进环境要求。
- **`Disconnect()` 之后 `ConnectedState()` 是 `ROBOTCOM_UNKNOWN(-1000) 'Sending command...'`**,
  不是 `DISCONNECTED`。判断掉线不能只看这一个值。
- RoboDK 可执行文件在 `C:\RoboDK\bin\RoboDK.exe`。
