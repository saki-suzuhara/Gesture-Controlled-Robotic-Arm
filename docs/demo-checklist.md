# 演示前检查清单

根据 `docs/grill-decisions.md` 整理,写于 2026-09-17。术语见 `CONTEXT.md`。标「Dobot」的只适用于 Nova 5,标「JAKA」的只适用于 JAKA Zu 20。

## 第一次上实机前(只做一次)

- [ ] 实测断连保险:在慢速运动中强行结束程序或拔掉网线,看机械臂停不停;经 RoboDK 控制时,再单独结束一次 RoboDK。不生效的话,就只靠实体急停和速度上限兜底,并记成一条 ADR。
- [ ] (Dobot)核实以下各项:
  - 控制器版本;
  - `RequestControl` 能否使用;
  - `dobot_sdk` 是否兼容;
  - 29999 端口能否被程序占用;
  - 零偏移的 `CalcTool` 是否返回原值;
  - `RobotMode` 和安全状态位的含义;
  - `SetCollisionLevel` 能否使用;
  - 逆解无解时的返回值。
- [ ] (JAKA)核实以下各项。2026-09-20 已答:驱动能连上 1.7.2(0.2–0.6 秒);连上不会自动上电使能(改成由人在示教器上做);底座在 0.5 m 台子上、正着装;J1 范围不用管。其余几项那次没做成——经 RoboDK 设不了速度,慢速运动做不出来,先定真机走哪条路(见 `docs/grill-decisions.md` 第三节):
  - 叫停:从按空格到机械臂停下要多久、停下前滑了多远(2026-09-20 用户定「暂时不测」,上实机做演示之前要补);
  - 碰撞保护、急停被按下时,程序能否知道;报错后能否清除、重新上电使能。
  - (已定,不用再测:路点和速度按法兰,控制器保持工具 0,见 ADR-0013。)
- [ ] (JAKA)核对程序设的速度真的受控(ADR-0011 的 2026-09-23 更新):示教器倍率调到约 25%,跑 `uv run python -m robot_side.scripts.speed_check --arm <填了 IP 的 jaka.toml 副本> --real`,看结论是不是「受控」。受控了,在那份副本的 `[speed]` 里加一行 `program_sets_speed = true`;不受控就不加,速度照旧全看示教器。
- [ ] (Dobot)在 DobotStudio Pro 里建好专用坐标系编号,并确认没人在用。
- [ ] 标定工作台坐标系,结果写进机械臂配置。指针偏移不再需要示教给控制器(路点按法兰,ADR-0013),量一个大概值记进配置就行,只用来算距离。
- [ ] (Dobot)录下真实的指令和应答,用来校准假控制器。

## 每次演示前

### 电脑

- [ ] 接上电源。
- [ ] 摄像头的隐私开关已打开。关着时,摄像头只给灰色占位图。
- [ ] 确认屏保和闲置锁屏不会在演示期间启动。
- [ ] 音量已打开,在操作位能听到提示音。
- [ ] 启动时指定了这台机械臂的机械臂配置,并加了连真机的开关;不加开关的话,程序只在 RoboDK 仿真里动。命令是 `uv run python main.py --arm <填了控制柜 IP 的 jaka.toml 副本> --real`(IP 不进仓库,副本放在仓库外)。
- [ ] 查一眼有没有上一次留下的 `JAKADriver.py` 进程(被 Ctrl-C 或杀掉的会留下,占着控制柜的连接);有就先停掉。
- [ ] 对准以后要等一阵才动:先把活动范围全查一遍(屏幕写 CHECKING RANGE n / 75;JAKA 第一次约 5–6 分钟,查过的存下来,配置和工作站不变就直接用),再连控制柜、查上电使能、热身约 20 秒。这期间机械臂不动。

### 现场

- [ ] 笔记本放在机械臂旁边:从操作位看,在机械臂左侧或右侧;在「机械臂臂展 + 指针长度」之外;屏幕和摄像头朝向操作位。
- [ ] 地上的操作位标记还在:离摄像头约 1.2 m,在「机械臂臂展 + 指针长度」之外。
- [ ] 屏幕倾角已调好:在预览窗口里看,画面从头顶拍到腰,手的活动范围都在检测区域的边框里。
- [ ] 人和笔记本都在「机械臂臂展 + 指针长度」之外,再留些余量:从底座转轴量,Nova 5 约 1.05 m,JAKA Zu 20 约 2.0 m。
- [ ] 急停盒拿在手里,线能拉到操作位。
- [ ] 旁人可以在场,但只有你的一只手做触发手势;任何人都可以在摄像头画面里张开手掌叫停,不在画面里的人就喊你,或按急停。

### 机械臂(Dobot)

- [ ] DobotStudio Pro 再现参数里的最大速度已调低(例如 250 mm/s);调整前,已和这台机械臂的其他使用者打过招呼。
- [ ] 机械臂处于下使能状态。如果已使能,程序会提示你先下使能,然后退出。
- [ ] 如果这台控制器不支持 `RequestControl`,先在 DobotStudio Pro 里手动切到 TCP/IP 模式。

### 机械臂(JAKA)

- [ ] 在示教器上给机械臂上电、使能。程序自己不做这一步,只检查;没上电使能,它不会下发运动。
- [ ] **在示教器上把速度倍率调好,并记下用的值。**机械臂配置开了 `program_sets_speed` 时,实际速度 = 演示配置里的速度 × 倍率(50 mm/s、倍率 25% 时约 12.5 mm/s);没开时程序不设速度,真机上走多快完全看这里设的。
- [ ] (要换待命位姿时)在示教器上把机械臂摆到想要的地方,跑 `uv run python -m robot_side.scripts.set_standby --arm <填了 IP 的 jaka.toml 副本> --real`:读进来、只转 J6 对上默认姿态,确认后写进那份配置。换过以后第一次启动会重查活动范围。
- [ ] 负载和碰撞等级按现场设好(2026-09-20 读到的是负载 2.0 kg、碰撞等级 5)。这些不写进机械臂配置。

### 程序启动后

- [ ] 预览窗口全屏,没有「按键无效」的红字提示。
- [ ] 启动检查通过(摄像头已打开、识别正常、画面不是一片灰)。
- [ ] 按提示站到操作位,把拳头举起来停约 2 秒(举在哪里都行),完成启动对准:响一声,出现检测区域和起点区的边框。这之后,程序才会连机械臂、上电。
- [ ] 对准时没有出现「离得太近」(TOO CLOSE)的提示。出现了,说明没站在胶带标记上,退回标记处重新对准;站得太近时,握拳平移会移得不够远。
- [ ] 所有路点都通过了可达性检查。
- [ ] 回待命倒计时开始时,你已站在操作位,手里拿着急停。

## 演示中

- 站在操作位标记上,照手势图例里的示范姿势做手势。
- 做手势都在起点区里,也就是对准时拳头所在的地方:握拳平移先停稳,看到 READY 再做;姿势保持也在这里摆。
- 握拳平移:左右上下是握着拳朝那个方向移过约 1.5 个拳头;往前(机械臂离你远一步)是握着拳往镜头推出去约 20 cm 停住;往后(机械臂朝你近一步)是握着拳像敲桌子那样往下点两下。
- 姿势保持:比 V → 画方块,竖拇指 → 原地点头,OK → 鞠躬,rock(食指加小指)→ 回待命。摆好后保持约 1 秒;要再做同一个,先放下手。
- 空闲时别顺手竖拇指(比如向旁人表示赞同):任何拇指朝上的手保持约 1 秒,都会触发原地点头;顺手比 OK 同理,会鞠躬。
- 动作做完不回待命位姿,停在那儿;下一个从那儿接着做(先右再上 = 停在右上)。左右最多各两步、上下最多各两步、前后各一步,再往外做屏幕上显示 OUT OF RANGE,机械臂不动。要回待命:趁空闲或冷却做 rock,或者走回笔记本按 H。
- 握拳平移做完,握着拳放下,别张开:手张开朝着镜头就是停止手势(2026-09-23 实测,「往上」之后最容易这样)。往前推完尤其要趁机械臂还在走就放下:等它走完、冷却结束以后再握着拳往下放,会被认成往下。
- 挪了位置、手势不灵时:趁空闲走回笔记本按 R,再回到操作位,把拳头举起来停约 2 秒,重新对准。
- 机械臂运动时出状况:张开手掌叫停,或者直接按急停;人在电脑前时,按空格叫停,预览窗口不在前台也行。
- 进入已停止(连响三声)后:先看现场,再走回笔记本前按回车。
- 退出程序:按 q 或 Esc。

## 演示后

- 程序退出后,机械臂保持使能、停在原地;需要时在 DobotStudio Pro 里下使能。
- 如果出现过已停止或误触发,看一下本地日志文件。
