# 第一版以 Dobot Nova 5 为载体,同时保留 JAKA 支持

项目最初面向 JAKA Zu 20(控制柜 1.7.2;原来写成 Zu 12,2026-09-19 用户更正),之后载体换成 Dobot Nova 5(V4 固件)。第一版先做 Nova 5 的实现并在它上面演示;JAKA 支持保留,之后在同一层机械臂接口下补上另一份实现,状态逻辑、演示配置和标定流程由两台共用。保留 JAKA,是因为以后 JAKA 更容易约到。

(2026-09-19 更新:机械臂一侧改用 RoboDK,上实机改为先上 JAKA;Nova 5 怎么接,仿真做完、约 Nova 5 之前再定。见 ADR-0011。演示仍在 Nova 5 上做,现在优先做 JAKA。)

## Consequences

- Nova 5 只能偶尔约到,平时开发依赖替身和假控制器,第一次上实机时要集中核实 Dobot 相关的未知项。(2026-09-19:平时开发改为在 RoboDK 仿真里做,替身不做了,假控制器和 Dobot 的核实随 Nova 5 的接法一起推迟。)
- JAKA 相关的待办(断连接口在 1.7.2 文档中已标为弃用、`jkrc` 在 Python 3.13 下的实际导入等)暂缓,开始做 JAKA 时再处理。(2026-09-19:JAKA 先上,这些待办提前。走 RoboDK 的驱动时,`jkrc` 由驱动在 RoboDK 自带的 Python 里调用,项目的 Python 3.13 不用导入它;断连保险要重新想,见 ADR-0011。)
