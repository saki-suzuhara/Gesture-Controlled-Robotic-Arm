# 前后两个方向:往前推、敲两下,挂在握拳平移的锁定上

左右上下之外,2026-09-23 用户要补前后:一步 100 mm,前后各一步(活动范围 ±Y 100 mm)。握拳平移只认画面里的位移,前后不在画面平面里,得另找两个做法。用户定:**往前(远离操作者)是握拳往镜头推出去停住,往后(朝操作者)是握拳像敲桌子那样往下点两下**;两个都算握拳平移的方向(`fist_move` + `forward` / `back`),先录原型再定规则。

2026-09-24 录了三批(`record --plan depth`,推、敲交替各 10 次),离线定的规则:

- **两个都挂在握拳平移的锁定上:**拳头先在起点区里停住、READY 锁定这只手,之后只看这只手;认出来就解除锁定,和左右上下同一套。
- **往前推看手框变大。**从最近 `move_max_s`(1.2 秒)里拳头连远近也停住(停住段里手框宽的变化不超过 15%)、手框最小的那一刻量起,手框宽到 1.4 倍、高到 1.2 倍,连着 3 帧,这 3 帧都是握拳类标签,中心没走出 1.5 个手宽。
- **敲两下看手框中心上下。**一下 = 往下 0.4 个手宽、再抬回 0.3 个手宽;3 秒内第二下往下一过门槛就算,不等它抬回来。手宽按最近停住时的手框宽量,不按启动对准那一个。那一段里握拳类标签的帧至少五成(没有手的帧也算在内)。

## Considered Options

规则上试过、没采用的:

- **推只看手框宽:**食指往旁边一指手框也会变宽(9-19 自由活动里一次),所以高也要变大。那次高是 1.0 倍。
- **推从最近那一刻量起:**推的时候中心几乎不动,只看中心的话推到一半还算停住。于是加了「远近也停住」。但推得慢时,刚起步那一段每 0.3 秒只大一点,照样算停住,起点跟着手往前挪:第三批 10 次漏 4 次、1 次被认成往下。所以改成从最近 1.2 秒里手框最小的那一刻量起。
- **推的高门槛 1.25:**有一次高 1.247 倍卡在门槛上,放到 1.2。宽的门槛放到 1.25 不多认出一次,只多出推一下报两次,留在 1.4。
- **敲两下等第二下抬回来才算:**实测第二下常常敲得更重,往下能走 1.3 个手宽;等它抬回来的话,握拳平移的「往下」(1.5 个手宽)可能先成立。
- **敲两下按启动对准的手宽量:**往前推完拳头举在镜头前,手框有对准时的将近两倍宽,手随便晃一下就够两下(第一批推完就冒出过一次往后)。
- **敲两下的握拳帧占比用平移那个 60%:**敲得快会模糊、认不出手,真敲两下最低 56%;说话时手指着旁边上下晃的那次是 44%,取 50% 分得开。

## Consequences

- **识别率(逐帧日志回放):**推三批合计 28/30,漏的两次一次在准备段就推了、一次准备时手不在画面里;敲两下后两批 18/20(第一批是热身,敲那几条多半做成了把拳头往回拉)。推和敲不互相认错。第三批按整张表算 18/20。
- **误触发:**拿以前录的 11 份(上下左右、自由活动、叫停,2026-09-17 到 09-23)回放,新规则一次没触发,原来那几个手势逐条结局一个没变。
- **推一下可能报两次:**第一次在还推着的时候就认出来了,解除锁定后手还在变大,紧接着又停住、又推大一截。这时机械臂已经在走,执行中不受理触发手势,所以不会多走一步;回放表里记成「多余」。
- **推完握着拳往下放,会被认成往下:**录像里歇一下那段有过两次。ADR-0014 定的习惯是「握拳平移做完握着拳放下」(免得张开的手被认成叫停),所以要趁机械臂还在走、冷却结束之前放下——那时不受理触发手势。
- **参数全在演示配置 `[vision]` 里**(`settle_size_percent`、`push_*`、`knock_*`),改了要重跑回放测试。三批录像的提示时间表标的是 forward / back;前两批录的时候规则还没接上,是事后改标的(原来那份存成 `timetable-free.json`)。
- **图例、调试按键跟着加:**图例写 `FORWARD (PUSH) = MOVE AWAY`、`BACK (KNOCK x2) = COME CLOSER`;调试按键 F、B。认出来的那一下画面里画不出箭头,改写 PUSH / KNOCK x2。
- **活动范围多了一层:**停靠点从 25 个变成 75 个。连真机前全查一遍(ADR-0014)的时间跟着变长,JAKA 第一次约 5–6 分钟,查过的结果存下来,配置和工作站不变就不再查。
- **还没在真机前站着验过**;2026-09-24 在 RoboDK 仿真里站着走过一遍,用户觉得推难认,之后才改成从最小那一刻量起。
