# Dobot 的速度硬上限放在控制器里,直线段下发绝对速度

Dobot V4 直线运动的绝对速度 `speed` 不受全局速度比例 `SpeedFactor` 影响,只受 DobotStudio Pro「再现参数」里的最大速度(以及缩减模式)限制。关节运动只能下发比例速度,实际比例 = `SpeedFactor` × 下发的比例。

因此在 Nova 5 上:
- **直线段:**按演示配置里的实际速度下发绝对速度。控制器一侧的硬上限,靠在 DobotStudio Pro 里把再现参数的最大速度手工调低(例如 250 mm/s)。
- **关节段:**下发前,程序先把演示配置里的百分比除以 `SpeedFactor`(20%),让配置里写的就是实际比例,与 JAKA 的换算一致。`SpeedFactor` 同时充当关节运动在控制器一侧的上限。
- **程序检查:**另按机械臂配置里的上限检查速度。

这样,演示配置里写的速度在两台机械臂上含义一致;即使程序出错,控制器也不会超过硬上限。

(2026-09-20 更新:JAKA 那一半「倍率对所有运动生效,由程序下发前换算掉」已被实测证伪——经 RoboDK 的 JAKA 驱动下发时,控制柜倍率不生效,程序也设不了速度。用户随后定:**不考虑倍率**,真机的速度和加速度由人在示教器上调好,程序不设速度、不换算。Dobot 那一半没有测过,随 Dobot 怎么接一起定。)

## Consequences

- 再现参数的最大速度是控制器里永久保存的设置,会影响这台机械臂上的其他程序。调整前要和其他使用者打招呼;换控制器或重置后要重新设置。
- 这个前提在代码里看不出来:如果忘了调低,直线段就只剩程序自身的检查这一层限制。
- 关节段的实际比例最多等于 `SpeedFactor`(20%),换算后超过 100% 的配置直接报错。机械臂配置里 Nova 5 的关节实际速度上限相应取 20%。
