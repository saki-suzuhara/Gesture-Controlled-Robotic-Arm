# 握拳平移只认从起点区出发的

握拳平移原型发现,「先停住再移动」分不出是有意的手势,还是挪位置的动作:
- 把拳头挪到起点时,40 次里触发 5–7 次,四个方向都有;
- 抬手组 10 次里,有 3–4 次被判成上移。

这几种误触发的动作有个共同点:把拳头挪到起点、抬到胸前、收回来,终点都在胸前,起点却不在。

因此,在画面里划出一块起点区:约 3 个手宽见方的方框,以每次启动对准时拳头的位置为中心(ADR-0008;对准时拳头举在哪里都行,原先写的是放在胸前)。程序不识别身体,只看手在不在这块方框里。

握拳平移只认从起点区出发的:
- 拳头在区里停稳时,预览窗口亮 READY,之后再移动才算;
- 停在区外再移动的,一律不算。

姿势保持也要在起点区里做。

## Considered Options

- **加使能手势:**最稳,但每个动作都多一步。如果起点区挡不住,就退回这个方案。
- **只收紧参数**(轴比 3、距离 1.75 个手宽等):误触发能降,但去不掉。
- **只把上、下改成姿势保持:**左右方向的误触发照样有。
- **全部改用姿势保持:**改动最大,而且保持姿势的识别率还没测。
- **不处理:**40 次里有 5–7 次,机械臂会无故动起来。

## Consequences

- **手势的做法变了:**所有触发手势都在起点区里做:握拳平移从这里出发,姿势保持在这里保持。握拳平移原型里的动作是从肩膀出发的;起点区原型实测了两轮,见下。
- **可能挡不住的情况一:**在起点区停住后,又随手把拳头放下,会被当成下移。起点区原型里没出现:两轮直接放下都是 0/10,放下时手很快就检测不到了;只有离线把用时放到 2.0 秒时出现 1 次。
  - 开写前检查的自由活动里出现了 1 次(坐着录的,3 分钟):手在耳边扶眼镜,停住时被认成 point(握拳类),READY 亮了;接着 0.15 秒里往下放了 1.58 个手宽,判成握拳下移。
  - 那次对准时拳头举在脸的高度,起点区盖住了耳边。只有这一只手,锁定挡不住;加「移动用时下限」离线验证过,也挡不住,因为判定会换一个更早的起点。
- **挡不住的情况二:换手误触发。**拳头在区里 READY 时,另一只手成了画面里最大的手,判定把这次跳变当成握拳平移。停住确实发生在区里,所以起点区挡不住。
  - 起点区原型第二轮出现 1 次(左手抬到脸前揉鼻子);
  - 换手误触发原型里,照提示做左手动作,16 次触发 7 次,每次 READY 的右拳都还在区里;
  - 只跟 READY 时那只拳头的跟踪编号,能全部挡住;已定这样改(ADR-0010)。这件事不必靠使能手势。
- **大小:**约 3 个手宽,是用户定的。区越大越好放,但抬手途中在区里停一下再往上,也越容易被当成上移。起点区原型里,站着从身侧抬拳进区是一个连贯的动作,中途不停;起点区 2、2.5、3、3.5 个手宽结果完全相同,暂时维持 3 个手宽。
- **位置:**跟着启动对准走;空闲时按 R 可以重新对准。
- **收手抑制仍有用:**原先以为收手的起点大多在区外,这条规则多半用不上。起点区原型第一轮里它挡掉了 1 次判反,所以维持。
- **挡不住时的退路:**实测挡不住的话,改用使能手势,ADR-0007 里「不设使能手势」的前提随之推翻。2026-09-17 用户定:设了起点区,不设使能手势;回放测试里加一段站着自由活动的录像,真出现误触发再说。开写前检查里坐着录的 3 分钟出现了 1 次(见上),按这条退路回到拷问;站着还没测。原地点头维持竖拇指,OK 仍空着(2026-09-18)。2026-09-19 用户定:顺手误触发不专门挡,「靠冷却、慢速、停止手势和急停兜底」,维持不设使能手势;另外站着重录一次自由活动。
- **起点区原型(2026-09-17)没能回答「挡不挡得住」:**
  - 两轮的抬拳进区都没触发(0/30、0/29),去掉起点区也一样,数据分不出有没有起点区的差别;换手误触发原型站着做,准备段也是 0/28;
  - 对照也没达标:站得比 1.2 m 近时 9/20,坐着约 1.2 m 时 18/20。
  - 用户后来定:起点区照设,不再专门测它的作用;不设使能手势(见上一条)。
